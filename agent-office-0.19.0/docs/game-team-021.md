# Tim Game & IT — lantai 2

Lima robot yang sudah ada mendapat tugas tambahan bersama: content=Pemantau Game, support=Teknisi IT, accounts=Teknisi Tampilan, payments=Teknisi Server, qa=Penguji Game. Identitas dan skill terdahulu dipertahankan.

Pemantau memeriksa HTTP halaman game terdaftar, empat halaman per 15 detik. Dua kegagalan berturut-turut diperlukan sebelum membuat insiden. Data pengguna, pesan error, token, dan stack tidak dikumpulkan. Ketersediaan halaman tidak membuktikan gameplay. Penerima browser diperluas ke identitas game terdaftar, tetapi cakupan pemasangan client dilaporkan terpisah.

Insiden masuk koordinator dan antrean perbaikan dengan satu penanggung jawab IT, spesialis tampilan/server dan penguji. Executor kode tetap otomasi terjadwal yang ada (60 menit); lima peran bukan lima model yang berjalan terus menerus. Tidak ada klaim perbaikan dalam detik.

Penempatan kantor: meja rapat lantai 2. Status berasal dari heartbeat worker dan antrean nyata; tidak ada hasil uji gameplay yang disintesis. Deploy kandidat terisolasi sebelum perubahan produksi.
